# Sample shop analytics

A tiny repository bundled with **Code Playground** to demonstrate the workspace.

- `main.py` — computes a discounted shopping total using `pricing.calculate_total`.
- `pricing.py` — the pricing rules.
- `analysis/usage.py` — selects usage hours with pandas and NumPy indexing.
- `config/settings.yaml` — configuration values.
- `data/` — sample CSV and JSON data.
- `assets/logo.svg` — a project logo.

Nothing in this repository is executed by Code Playground.
